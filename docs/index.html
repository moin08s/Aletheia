Aletheia Forensic Instrument Overview

Aletheia is an institutional-grade Decentralized Digital Forensics & Incident Response (DeDFIR) platform. It bridges host-level forensic artifacts with Base L2 rollups and Ethereum Attestation Service (EAS) schemas.

Available Evaluation Controls:
  • Case Selector: Toggle between CASE-2026-LIVE, NIST M57-Jean, and DeFi Vault Drain.
  • Interactive Scrubber: Click bars or play automated breach replay.
  • On-Chain Verification: Audit local files against the Base Sepolia smart contract.
  • ZK-Selective Disclosure: Generate Groth16 proofs proving an incident without PII leaks.
